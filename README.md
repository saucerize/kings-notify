# kings-notify

琉球ゴールデンキングスの試合を通知するツールと、「次の試合」を表示する Web ページです。

- `notifier.py` … 試合の速報を通知するスクリプト（GitHub Actions で動作）
- `docs/` … 「次の試合」ページ（GitHub Pages で公開）

## 「次の試合」ページ

`docs/` フォルダの中身がそのまま Web サイトになります。

| ファイル | 内容 |
| --- | --- |
| `docs/index.html` | ページ本体（スマホ向け・黒×ゴールドのデザイン） |
| `docs/schedule.json` | 試合予定（ページはここから読み込みます） |

表示される内容:

- 次の試合の日付・時間・対戦相手・会場・ホーム/アウェイ
- 試合開始までのカウントダウン（試合中は「試合開始から」の経過時間）
- その後の予定の一覧

終わった試合は自動でとばします。試合開始から 2 時間 30 分たつと「終わった」とみなし、次の試合を表示します（`index.html` の `GAME_LENGTH_MS` で変更できます）。

### 試合予定の書き方

`docs/schedule.json` の `games` に 1 試合ずつ書きます。今入っている 3 試合は **仮の予定** です。

```json
{
  "datetime": "2026-11-01T15:05:00+09:00",
  "opponent": "千葉ジェッツ",
  "venue": "沖縄サントリーアリーナ",
  "home": true
}
```

| 項目 | 説明 |
| --- | --- |
| `datetime` | 試合開始日時。末尾の `+09:00`（日本時間）を忘れずに |
| `opponent` | 対戦相手 |
| `venue` | 会場 |
| `home` | ホームなら `true`、アウェイなら `false` |

- 書く順番は自由です（日時順に並べ替えて表示します）。
- 終わった試合は消さなくても大丈夫です（自動でとばします）。
- `note` に書いた文はページ下に小さく表示されます。不要なら `"note": ""` にしてください。
- JSON は最後の項目の後ろにカンマ `,` を付けるとエラーになるので注意してください。

## GitHub Pages で公開する手順

1. このリポジトリの変更を `main` ブランチに入れます（プルリクエストをマージ）。
2. GitHub でリポジトリを開き、上の **Settings** をクリックします。
3. 左のメニューから **Pages** を開きます。
4. **Build and deployment** の **Source** で **Deploy from a branch** を選びます。
5. **Branch** で `main` を選び、その右のフォルダで `/docs` を選んで **Save** を押します。
6. 1〜2 分待つと、同じ画面の上部に公開 URL が表示されます。
   例: `https://saucerize.github.io/kings-notify/`
7. URL をスマホで開いて表示を確認します。ホーム画面に追加しておくとアプリのように使えます。

※ 無料プランでは、GitHub Pages はリポジトリが **Public（公開）** の場合のみ使えます。

### 予定を更新するとき

`docs/schedule.json` を編集して `main` ブランチにコミットすると、数分でサイトに反映されます。GitHub の画面上でファイルを開き、鉛筆アイコンから直接編集しても OK です。

### 手元のパソコンで確認したいとき

`index.html` をダブルクリックで開くと、ブラウザの制限で `schedule.json` を読み込めません。次のように簡易サーバーを起動して確認してください。

```sh
cd docs
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開きます。
